# IAI_SLE2

## SLE-2: BFS and DFS with Performance Measurement and py-spy

This project implements **Breadth First Search (BFS)** and **Depth First Search (DFS)** using the graph supplied for the SLE-2 task.

The program:
- Uses an adjacency-list graph.
- Searches from **A** to **W**.
- Runs BFS and DFS three times.
- Measures execution time using Python's `time.perf_counter()`.
- Calculates best, average and worst execution time.
- Counts nodes expanded.
- Can be profiled using **py-spy**.

## Graph

The graph used in the program is:

```text
                         A
                       /   \
                      C     B
                    /  \   / \
                   G    H D   E
                  / \  / \   / \
                 O   P K  L I   J
                 |  / \
                 W Q   R
                   |  / \
                   S T   U

                 D -> F
                 F -> M, N, V
```

The complete graph is stored in `GRAPH` inside `bfs_dfs.py`.

## BFS

BFS uses a **queue** and explores the graph level by level.

For this graph, starting at **A** and searching for **W**, the path returned is:

```text
A -> C -> G -> O -> W
```

## DFS

DFS uses a **stack** and explores one branch deeply before backtracking.

With the neighbor order used in the supplied DFS code, the path returned to **W** is:

```text
A -> C -> G -> O -> W
```

BFS and DFS may visit nodes in different orders and may expand a different number of nodes before reaching the goal.

## Performance Measurement

Both algorithms are executed three times.

For each algorithm the program displays:
- Run 1 time
- Run 2 time
- Run 3 time
- Best time
- Average time
- Worst time
- Nodes expanded

Execution time is measured in milliseconds using:

```python
time.perf_counter()
```

The measured values can vary between runs because they depend on the local computer and system load.

## py-spy Profiling

### Generate profile.svg

Run:

```powershell
py-spy record --output profile.svg -- python bfs_dfs.py
```

This generates the actual **profile.svg** flame graph.

### Live profiling

```powershell
py-spy top -- python bfs_dfs.py
```

### Important

`graph.svg` is the graph visualization.

`profile.svg` is the performance profile generated by **py-spy**.

Do not manually claim that `profile.svg` is generated until the py-spy command has actually been run.

## Complexity

For an adjacency-list graph:

| Algorithm | Time Complexity | Space Complexity |
|---|---|---|
| BFS | O(V + E) | O(V) |
| DFS | O(V + E) | O(V) |

Where:
- **V** = number of vertices
- **E** = number of edges
